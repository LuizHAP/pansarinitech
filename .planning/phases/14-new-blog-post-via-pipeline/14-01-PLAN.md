<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OpenAI API → MDX body | AI-generated content is owner-controlled. `next-mdx-remote@^6` `blockJS: true` strips JS expressions. |
| Pipeline state → Filesystem | Pipeline writes `.pipeline-state.json` directly from computed state (not model output). |
| MDX body → JSON-LD | Post title/excerpt are interpolated into JSON-LD via `buildMetadata()`. XSS-safe via json-ld.tsx escaping. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-01 | Tampering / XSS via AI content | AI-generated MDX body | mitigate | next-mdx-remote@^6 `blockJS: true` strips `{expr}` JS. Only registered MDX components render. |
| T-14-02 | Tampering / Path traversal | Pipeline file writes | mitigate | Pipeline uses ALLOWED_PATHS set to only write to expected paths. |
| T-14-03 | Information disclosure / Pipeline state | .pipeline-state.json | mitigate | State file contains only topic metadata — no sensitive data. |
</threat_model>
