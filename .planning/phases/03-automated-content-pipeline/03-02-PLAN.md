    WORKFLOW HEADER:
      name: Generate Blog Post
      on:
        schedule:
          - cron: "0 9 */5 * *"    # per D-01; days 1, 6, 11, 16, 21, 26, 31 of each month at 09:00 UTC
        workflow_dispatch:           # per D-01; manual trigger from GitHub Actions UI

    JOB:
      jobs:
        generate-post:
          runs-on: ubuntu-latest
          timeout-minutes: 15        # content generation needs more runway than ci.yml's 8 min
          permissions:
            contents: write          # per RESEARCH.md Pattern 3; required for git push
            pull-requests: write     # per RESEARCH.md Pattern 3; required for gh pr create

    STEPS (in order):

    1. actions/checkout@v4 — copy from ci.yml verbatim

    2. Setup pnpm — copy pnpm/action-setup@v4 from ci.yml verbatim

    3. Setup Node 22 — copy actions/setup-node@v4 with node-version: 22 and cache: pnpm from ci.yml verbatim

    4. Install (frozen lockfile) — pnpm install --frozen-lockfile, copy from ci.yml verbatim

    5. "Install Claude CLI":
       run: npm install -g @anthropic-ai/claude-code
       (per D-02; installs the `claude` binary on PATH)

    6. "Configure git identity":
       run: |
         git config user.email "github-actions[bot]@users.noreply.github.com"
         git config user.name "github-actions[bot]"
       (required before any git commit; runners have no default identity — RESEARCH.md anti-patterns)

    7. "Resolve topic and slug":
       id: topic
       run: |
         TODAY=$(date -u +%Y-%m-%d)
         LAST=$(node -e "
           const fs = require('fs');
           const state = fs.existsSync('content/blog/.pipeline-state.json')
             ? JSON.parse(fs.readFileSync('content/blog/.pipeline-state.json', 'utf8'))
             : { last_topic: null };
           console.log(state.last_topic || 'null');
         ")
         NEXT=$(node -e "
           const seq = ['nextjs-react-frontend','software-engineering-career','ai-in-development','personal-projects-open-source'];
           const last = process.argv[1] === 'null' ? null : process.argv[1];
           const idx = last === null ? 0 : (seq.indexOf(last) + 1) % seq.length;
           console.log(seq[idx]);
         " "$LAST")
         SLUG=$(echo "${NEXT}-$(date -u +%Y%m%d)" | tr '[:upper:]' '[:lower:]' | sed 's/[^a-z0-9-]/-/g')
         echo "today=$TODAY" >> $GITHUB_OUTPUT
         echo "topic=$NEXT" >> $GITHUB_OUTPUT
         echo "slug=$SLUG" >> $GITHUB_OUTPUT
       Notes:
         - The tr + sed normalization guards against slug regex failure (RESEARCH.md Pitfall 3)
         - SLUG combines NEXT_TOPIC + date only (no HHMM) — the BRANCH gets the HHMM suffix (Pitfall 5)

    8. "Generate bilingual MDX post":
       env:
         ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
         TOPIC: ${{ steps.topic.outputs.topic }}
         SLUG: ${{ steps.topic.outputs.slug }}
         TODAY: ${{ steps.topic.outputs.today }}
       run: |
         STYLE_REF=$(cat content/blog/building-this-portfolio.en.mdx)
         PROMPT_TEMPLATE=$(cat scripts/generate-post-prompt.md)
         PROMPT=$(echo "$PROMPT_TEMPLATE" | sed "s|\${SLUG}|${SLUG}|g; s|\${TOPIC}|${TOPIC}|g; s|\${TODAY}|${TODAY}|g")
         FULL_PROMPT="${PROMPT}

         ## Style reference (match this voice and structure):
         ${STYLE_REF}"
         claude --print -p "$FULL_PROMPT" \
           --permission-mode acceptEdits \
           --allowedTools "Read,Write,Edit,Bash(git status)" \
           --no-session-persistence \
           --model claude-sonnet-4-6
       Notes:
         - Uses --print per D-02 (headless mode, outputs to stdout; file writes happen via Write tool)
         - STYLE_REF injected at the end to keep the prompt template readable
         - --model claude-sonnet-4-6 per RESEARCH.md Open Question 1 recommendation

    9. "Assert generated files exist":
       env:
         SLUG: ${{ steps.topic.outputs.slug }}
       run: |
         test -f "content/blog/${SLUG}.en.mdx" || { echo "ERROR: EN file not generated"; exit 1; }
         test -f "content/blog/${SLUG}.pt.mdx" || { echo "ERROR: PT file not generated"; exit 1; }
         echo "Both locale files present."
       (Guards against Pitfall 6 — claude exits 0 but files were not written)

    10. "Verify blog content (parity + Zod)":
        run: pnpm verify:posts
        (Validates frontmatter + bilingual parity before branch is created; per RESEARCH.md recommendation and D-02 scope)

    11. "Create branch and commit":
        env:
          SLUG: ${{ steps.topic.outputs.slug }}
          TODAY: ${{ steps.topic.outputs.today }}
          TOPIC: ${{ steps.topic.outputs.topic }}
        run: |
          BRANCH="content/auto-post-$(date -u +%Y-%m-%d-%H%M)"
          git checkout -b "$BRANCH"
          git add "content/blog/${SLUG}.en.mdx" "content/blog/${SLUG}.pt.mdx" "content/blog/.pipeline-state.json"
          git commit -m "content(auto): ${TOPIC} post ${TODAY}"
          git push origin "$BRANCH"
        Notes:
          - BRANCH uses +%Y-%m-%d-%H%M (not date-only) to prevent same-day collision (Pitfall 5 per D-11 extended per research)
          - .pipeline-state.json added explicitly — glob would miss dotfiles (RESEARCH.md anti-patterns)

    12. "Open PR":
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          TOPIC: ${{ steps.topic.outputs.topic }}
          TODAY: ${{ steps.topic.outputs.today }}
        run: |
          gh pr create \
            --title "[auto] Blog post: ${TOPIC} (${TODAY})" \
            --body "$(cat <<'BODY'
          ## Automated blog post — review checklist

          - [ ] Frontmatter valid: date (YYYY-MM-DD), excerpt (40–280 chars), tags present
          - [ ] PT version reads naturally — not a literal translation
          - [ ] No inline JS or dynamic imports in MDX body
          - [ ] Flip \`draft: false\` to publish (or leave \`true\` to merge without publishing)

          > Generated by the automated content pipeline. Merge to add to repo; flip draft to publish.
          BODY
          )" \
            --base main
        (PR body per D-10 checklist; GH_TOKEN auto-issued by GitHub Actions; --base main per D-11)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner → ANTHROPIC_API_KEY | Secret injected via env; never logged or printed |
| claude agent → repo filesystem | Agent runs with --permission-mode acceptEdits + restricted --allowedTools; cannot execute arbitrary shell |
| generated MDX → next-mdx-remote renderer | blockJS: true blocks any inline JS that slips through the prompt |
| GITHUB_TOKEN → GitHub API | Scoped to contents: write + pull-requests: write; cannot merge PRs or modify settings |
| workflow YAML → repo | Workflow changes are visible in git history; malicious prompt injection would require repo write access |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Information Disclosure | ANTHROPIC_API_KEY in env | mitigate | Secret injected as GitHub Actions encrypted secret; never echo'd or written to files; runner logs do not expose env secrets per GitHub Actions security model |
| T-03-05 | Tampering | claude agent file writes | mitigate | --allowedTools "Read,Write,Edit,Bash(git status)" limits agent to filesystem ops on checked-out repo + read-only git status; no network, no arbitrary shell; agent cannot push or create PRs |
| T-03-06 | Elevation of Privilege | GITHUB_TOKEN pr creation | mitigate | permissions: block limits to contents: write + pull-requests: write; token cannot approve PRs (repo setting "Allow GitHub Actions to create and approve PRs" — the second capability is NOT enabled, only creation) |
| T-03-07 | Denial of Service | cron run cost | accept | ~12 runs/year at ~$0.05/run = ~$0.60/year; cost is negligible; no rate-limit risk at this volume |
| T-03-08 | Tampering | Prompt injection via STYLE_REF | accept | STYLE_REF is a static committed file (building-this-portfolio.en.mdx); no user input involved; anyone with repo write access who tampers with it has repo write access already |
| T-03-09 | Tampering | Generated MDX inline JS | mitigate | Prompt explicitly forbids JS; pnpm verify:posts catches structural issues; next-mdx-remote blockJS: true strips any JS that reaches the renderer; three-layer defense |
| T-03-10 | Repudiation | Automated commits | accept | git commit author is "github-actions[bot]"; PR title prefix "[auto]" marks automated posts; full audit trail in git history and GitHub Actions run logs |
</threat_model>
