  <action>
    Create `src/app/[locale]/blog/feed/route.ts` — a Next.js App Router route handler that generates RSS 2.0 XML dynamically.

    The route handler must:
    1. Accept GET requests at `/feed.xml` and `/feed.pt.xml`
    2. Call `getPosts(locale)` to fetch published posts (draft-filtered in production)
    3. Limit to 20 most recent posts via `.slice(0, 20)`
    4. Generate RSS 2.0 XML with proper structure:
       - `<?xml version="1.0" encoding="UTF-8"?>`
       - `<rss version="2.0" xmlns:atom="http://www.w3.org/2005/Atom">`
       - `<channel>` with: title, link, description, language, atom:link (self), lastBuildDate
       - `<item>` for each post: title, link, pubDate, description, guid
    5. Return `NextResponse` with `Content-Type: application/rss+xml; charset=utf-8`
    6. Escape all XML special characters in title/excerpt using `escapeXml()`

    RSS 2.0 structure:
    ```xml
    <?xml version="1.0" encoding="UTF-8"?>
    <rss version="2.0" xmlns:atom="http://www.w3.org/2005/Atom">
      <channel>
        <title>Luiz Pansarini — Blog</title>
        <link>{SITE_URL}/blog</link>
        <description>Principal Software Engineer — technical writing</description>
        <language>{locale === 'pt' ? 'pt-BR' : 'en'}</language>
        <atom:link href="{feedUrl}" rel="self" type="application/rss+xml"/>
        <lastBuildDate>{new Date(posts[0].date).toUTCString()}</lastBuildDate>
        {items}
      </channel>
    </rss>
    ```

    Where each item is:
    ```xml
    <item>
      <title>{escapeXml(post.title)}</title>
      <link>{SITE_URL}/blog/{post.slug}</link>
      <pubDate>{new Date(post.date).toUTCString()}</pubDate>
      <description>{escapeXml(post.excerpt)}</description>
      <guid>{SITE_URL}/blog/{post.slug}</guid>
    </item>
    ```

    The `escapeXml()` function must handle: `&`, `<`, `>`, `"`, `'`.

    Note: The route handler is at `src/app/[locale]/blog/feed/route.ts`. Since the site uses `localePrefix: 'never'`, the locale is determined by the cookie, not the URL. The route handler receives the locale from `params`.

    After creating the file, run `pnpm build` to verify no TypeScript errors.
  </action>
