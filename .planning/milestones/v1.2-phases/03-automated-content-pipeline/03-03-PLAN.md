<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Anthropic Console → GitHub Secrets | ANTHROPIC_API_KEY value travels over HTTPS to GitHub's encrypted secret store; not visible in logs |
| human → GitHub UI | The enabling of "Allow GitHub Actions to create PRs" is a one-time privileged action that only repo admins can perform |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-11 | Information Disclosure | ANTHROPIC_API_KEY secret value | mitigate | Key is stored in GitHub encrypted secrets, never printed in logs, scoped to this repo only; rotate if a workflow step accidentally echoes it |
| T-03-12 | Elevation of Privilege | "Allow Actions to create PRs" repo setting | accept | Only repo admins can enable this; Luiz is the sole admin; the permission allows PR creation by Actions only, not PR approval; human review gate is still required before merge |
| T-03-13 | Tampering | Malicious PR submitted by automated workflow | accept | All generated PRs require Luiz's manual review and merge; draft: true frontmatter prevents accidental publish before review; the PR checklist documents what to verify |
</threat_model>
