## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps within command items (`gap-1`) |
| sm | 8px | Horizontal padding on trigger button (`px-2`), palette internal gaps |
| md | 16px | Palette dialog padding, group separator vertical spacing |
| lg | 24px | Palette max-height breathing room (top/bottom padding) |
| xl | 32px | — |
| 2xl | 48px | — |
| 3xl | 64px | — |

Exceptions:
- Touch targets: 44px minimum (`h-11 min-w-[44px]`) — WCAG 2.5.5 compliance. Applies to header trigger button and all tappable command items on mobile.
- Command item height: 32px (`h-8`) on desktop, inherits cmdk default. Matches existing Shadcn component sizing in this project.
- Palette dialog width: `max-w-[640px]` (desktop), `w-[calc(100%-32px)]` (mobile — 16px margin each side at 375px viewport).

## Color

Source: existing `globals.css` OKLCH tokens — palette components inherit all tokens via CSS variables. No new color values introduced.

| Role | CSS Token | Jedi (Light) | Sith (Dark) | Usage |
|------|-----------|--------------|-------------|-------|
| Dominant (60%) | `--background` | `oklch(98% 0.005 250)` | `oklch(10% 0.01 250)` | Page background (behind backdrop) |
| Secondary (30%) | `--popover` | `oklch(98% 0.005 250)` | `oklch(15% 0.012 250)` | Palette dialog surface (CommandDialog uses `--popover`) |
| Card surface | `--card` | `oklch(94% 0.008 250)` | `oklch(15% 0.012 250)` | Not used directly in palette |
| Muted surface | `--muted` | `oklch(90% 0.012 250)` | `oklch(18% 0.015 250)` | Hovered/selected command item background |
| Accent (10%) | `--accent` / `--primary` | `oklch(55% 0.18 250)` — Jedi blue | `oklch(54% 0.21 28)` — Sith red | Selected item indicator; focus ring color (`--ring`); active command icon tint |
| Foreground | `--popover-foreground` | `oklch(12% 0.01 250)` | `oklch(94% 0.008 250)` | Command item text, group heading text |
| Muted foreground | `--muted-foreground` | `oklch(38% 0.01 250)` | `oklch(70% 0.015 250)` | Placeholder text in `<CommandInput>`, keyboard badge text, empty state copy |
| Border | `--border` | `oklch(82% 0.018 250)` | `oklch(25% 0.02 250)` | Palette dialog border, separator lines between groups |
| Destructive | `--destructive` | `oklch(50% 0.22 27)` | `oklch(65% 0.22 28)` | No destructive commands in palette (Phase 1 has no delete/remove actions) |

Accent reserved for:
- Focus ring on command items (`outline: 2px solid var(--ring)`, `outline-offset: 2px`)
- The active/selected item highlight background in cmdk (`[aria-selected=true]` → `bg-accent text-accent-foreground`)
- The header trigger button's ⌘K badge text on hover (inherits `text-muted-foreground` at rest, no accent on static state)
- Icon tint for the trigger button icon on hover state (Shadcn ghost button: `hover:bg-muted hover:text-foreground` — does NOT use accent, keeps accent reserved)

Backdrop overlay: Shadcn Dialog default — `bg-black/80` (Radix Dialog overlay). Applies on top of page content when palette is open.

## Component Specifications

### 1. Header Trigger Button

**Source of truth:** D-08, D-09, D-10

| Property | Value |
|----------|-------|
| Base component | `<Button variant="ghost" size="icon">` from `@/components/ui` |
| Icon | `Search` from `lucide-react` (`h-5 w-5`, `aria-hidden="true"`) |
| Touch target | `h-11 w-11` (44px square) — overrides `size="icon"` default of `size-8` (32px) |
| Mobile | Icon only; ⌘K badge hidden via `hidden md:inline` |
| Desktop (md+) | Icon + `⌘K` text badge beside it |
| Badge styling | `text-xs text-muted-foreground` — no border, no pill shape; plain text |
| Layout | `className="h-11 min-w-[44px] gap-1 px-2"` |
| `aria-label` | `t('commandPalette.triggerLabel')` — "Open command palette" (EN) / "Abrir painel de comandos" (PT) |
| Position in header | Between `<LocaleToggle />` and `<ThemeToggle />` |

Rationale for `Search` icon over `Command`: `Search` (magnifying glass) is universally recognized as a search/find action — more immediately clear to non-technical users (recruiters). The ⌘K text badge on desktop provides the keyboard shortcut context for technical users.

### 8. Close Button (Mobile Dismiss — UX-07)

Provided automatically by `showCloseButton={true}` on `<CommandDialog>`. Shadcn `new-york-v4` template renders an `✕` icon button in the top-right corner of the dialog.

| Property | Value |
|----------|-------|

### 9. Open/Close Animation

| Property | Value |
|----------|-------|
| Approach | Shadcn Dialog built-in CSS transition (Radix Dialog `data-[state=open]` / `data-[state=closed]` attributes) |
| Effect | Fade + scale — Shadcn default: `animate-in fade-in-0 zoom-in-95` on open, `animate-out fade-out-0 zoom-out-95` on close |
| Duration | 150ms (Shadcn/Radix default) |
| `motion` package | Not used for palette open/close — Shadcn Dialog defaults are sufficient and avoid an extra dependency for a standard transition |
| Reduced motion | Covered by `globals.css` line 77–85: `animation: none !important` under `prefers-reduced-motion: reduce`. The palette dialog will open/close instantly for RM users. |

### 10. Focus Ring

| Property | Value |
|----------|-------|
| Style | `outline: 2px solid var(--ring)` |
| Offset | `outline-offset: 2px` |
| Color (Jedi) | `oklch(55% 0.18 250)` — Jedi blue |
| Color (Sith) | `oklch(58% 0.21 28)` — Sith red (note: `--ring` in dark mode uses `58%`, slightly brighter than `--primary` at `54%`, to maintain 3:1 focus ring contrast against dark backgrounds per WCAG 1.4.11) |
| Applied by | `globals.css` `*:focus-visible` rule (line 88) — applies globally including palette items |
| cmdk items | cmdk applies `[aria-selected=true]` for keyboard navigation; the focused item uses the `bg-accent` background state, NOT an outline ring. The Radix Dialog close button uses the global `focus-visible` outline. |
| Contrast requirement | WCAG 1.4.11 Non-text Contrast: 3:1 minimum. Jedi blue on white surface: ~4.8:1 (passes). Sith red `oklch(58%)` on dark surface `oklch(10%)`: ~5.2:1 (passes). |

## Interaction Contract

### Global Keyboard Shortcut

| Condition | Behavior |
|-----------|----------|
| `Cmd+K` (macOS) anywhere on page | Opens palette (toggles if already open) |
| `Ctrl+K` (Windows/Linux) anywhere on page | Opens palette (toggles if already open) |
| `e.preventDefault()` | Required — Chrome intercepts Cmd+K for URL bar without it |
| Palette already open + Cmd+K | Closes palette |

### While Palette is Open

| Input | Behavior |
|-------|----------|
| `Escape` | Closes palette; focus returns to previously focused element (Radix Dialog built-in) |
| `Arrow Down` / `Arrow Up` | Moves selection between command items (cmdk built-in) |
| `Enter` | Executes selected command (cmdk built-in) |
| `Tab` | Not used for item navigation — cmdk uses arrow keys; Tab is available for dialog-internal focus cycling (close button) |
| Click backdrop | Closes palette (Radix Dialog `onOpenChange` built-in) |
| Tap close button (`✕`) | Closes palette (mobile primary dismiss path) |
| Focus trap | Focus is contained within dialog while open (Radix Dialog built-in) |
| Type characters | Filters command items live via cmdk built-in string matching |

### Command Execution Sequence

All command items follow this sequence on select:

1. `setOpen(false)` — close dialog
2. `requestAnimationFrame(action)` — execute action after dialog starts closing

This prevents visual competition between the dialog overlay and the executed action (required for theme swap per D-05; consistent for all commands).

### Theme Toggle Command

- Reads `resolvedTheme` from `useTheme()`
- Calls `setTheme(isDark ? 'light' : 'dark')` directly (NO `startViewTransition` — D-04)
- Close-then-act sequence: `setOpen(false)` → `requestAnimationFrame(() => setTheme(next))`
- Icon reflects current theme state: `Sun` when in Jedi mode, `Moon` when in Sith mode

### Locale Switch Commands

- Calls `switchLocale(target)` server action directly from `onSelect`
- Both PT and EN commands always visible regardless of active locale (D-07)
- Triggers page reload (server action sets cookie + redirects) — palette unmounts naturally
- No explicit `setOpen(false)` needed before locale switch (page reload closes everything), but calling it anyway is harmless and consistent

### Navigate-to Commands

- Calls `document.getElementById(id)?.scrollIntoView({ behavior: 'smooth' })`
- `prefers-reduced-motion` handled by `globals.css` `scroll-behavior: auto !important` rule — safe to always pass `behavior: 'smooth'`
- Blog navigation: `useRouter().push('/blog')` via `@/lib/i18n/navigation` (locale-prefixed route)

### Link Commands

- Resume PDF: `window.open(path, '_blank', 'noopener')` — opens PDF in new tab
- LinkedIn/GitHub: `window.open(url, '_blank', 'noopener')` — opens in new tab
- `noopener` is required for security (prevents `window.opener` access from the new tab)

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| UX-06: Focus trap | Radix Dialog built-in (`DialogContent` portal with `FocusScope`) |
| UX-06: Escape dismiss | Radix Dialog built-in (`onEscapeKeyDown` → `onOpenChange(false)`) |
| UX-06: Arrow navigation | cmdk `CommandList` + `CommandItem` built-in (roving tabindex) |
| UX-06: Enter executes | cmdk `onSelect` callback |
| UX-07: Mobile dismiss | `showCloseButton={true}` on `CommandDialog` + backdrop tap |
| WCAG 1.4.3 AA (text contrast) | All text uses established tokens verified against dark/light surfaces |
| WCAG 1.4.11 (non-text contrast) | Focus ring: 3:1 minimum — Jedi ~4.8:1, Sith ~5.2:1 (see Focus Ring section) |
| WCAG 2.5.5 (touch target) | Header trigger: `h-11 min-w-[44px]` = 44px — meets AA |
| WCAG 4.1.2 (ARIA dialog) | `role="dialog"`, `aria-modal="true"`, `aria-labelledby` → dialog title — Radix Dialog built-in |
| Screen reader announcement | `title` prop on `CommandDialog` provides accessible name; `description` prop provides context |
| `prefers-reduced-motion` | Dialog animation suppressed by `globals.css` line 77–85; scroll behavior suppressed by `scroll-behavior: auto !important` |
