## Implementation Notes

### Shadcn Template Version
- Generated by `npx shadcn@latest add command dialog` using the `radix-nova` preset (confirmed in `components.json`: `style: radix-nova`, `baseColor: neutral`, `cssVariables: true`).
- Shadcn CLI also generated peer dependencies: `input.tsx`, `textarea.tsx`, `input-group.tsx` (required by `CommandInput` which wraps `InputGroup`).

### Import Normalization
- `dialog.tsx` was generated with `import { Dialog as DialogPrimitive } from 'radix-ui'` — already correct. No post-generation normalization was required for the Dialog radix import.
- `command.tsx` correctly imports from `'cmdk'` and re-imports Dialog from the local `@/components/ui/dialog` file (not from radix-ui directly).
- Biome normalized double → single quotes and import ordering on all generated files.

### CommandDialog showCloseButton Default
- Shadcn generated `showCloseButton = false` on `CommandDialog`.
- Changed to `showCloseButton = true` to satisfy UX-07 (mobile dismiss affordance via close button in top-right corner of dialog).
- The `DialogContent` inside `CommandDialog` renders the `XIcon` close button when `showCloseButton={true}` (inherited from the `DialogContent` pattern in `dialog.tsx` lines 62-69, mirroring `sheet.tsx`).

### cmdk Version
- `cmdk@1.1.1` installed via the Shadcn CLI.

### i18n Namespace
- All 22 keys from UI-SPEC.md §"Copywriting Contract" populated exactly as specified.
- `commandPalette` inserted after `blog` and before `mdx` in both locale files (alphabetically: `blog` → `commandPalette` → `mdx` — correct alphabetical order for c between b and m).
- PT strings are MEDIUM confidence per RESEARCH.md §Assumption A1. Luiz must review PT strings before the PR merges (they are proposed translations, not confirmed author-language copy).
