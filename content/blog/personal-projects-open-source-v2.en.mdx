## Introduction

Every engineer's journey through open source development is unique, shaped by personal experiences and challenges. In this post, I explore my technical adventures in building open source projects, highlighting the decisions that shaped their trajectories, and the pitfalls I navigated along the way.

## Balancing Innovation with Practicality

Working with open source projects often involves striking a balance between innovation and practicality. **Next.js** allowed for rapid prototyping with its **React Server Components** and **Turbopack**, enabling swift iterations while maintaining performance.

### **Decision-Making with Supabase**

For the **DoAção** project, a platform connecting volunteers with local businesses, leveraging **Supabase** was crucial. The platform required real-time updates and robust security, and Supabase's **row-level security (RLS)** played a key role in ensuring data integrity while handling users' personal information securely.

<Note>Supabase's `RLS` helps in accessing and modifying data securely, reducing data breaches associated with direct database access.</Note>

## Key Challenges

### Integration with Discord for MTG Price Monitor

**Real-time integrations** are often more complex than they seem. In the **MTG Price Monitor** project, using **Discord.js** to notify users of Magic: The Gathering card price changes, I faced challenges in handling Discord bot rate limits and ensuring consistent data updates across multiple marketplaces.

<Warning>Always adhere to Discord's API limits to avoid being banned. Carefully handle request timing and retry logic.</Warning>

### Schema Design in Drizzle ORM

Another challenge was designing schemas in **Drizzle ORM** effectively. It’s pivotal to consider future scalability while implementing database schemas. This could prevent costly refactors when the system demands increased complexity or new features.

<CodeFilename filename="src/server/db.ts">
```typescript
import { defineSchema } from 'drizzle-orm';

const schema = defineSchema({
  points: {
    type: 'integer',
    primary: true,
  },
  rewards: {
    type: 'text',
    unique: true,
  },
});
```
