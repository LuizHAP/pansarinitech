Aurebesh font binary attribution + license
============================================

File: ft-aurebesh.woff2

Source: Aurebesh_Rodian (beta) by AurekFonts
Origin: https://github.com/AurekFonts/Aurebesh_Rodian (master branch)
Original format: Aurebesh_Rodian_beta.otf
Conversion: OpenType -> WOFF2 via fontTools (Python). No glyph
  modifications; the binary is a re-encoded copy of the upstream OTF
  preserving all glyphs, kerning, and metadata.

License: MIT (per github.com/AurekFonts/Aurebesh_Rodian/blob/master/LICENSE)

Used in this project:
- Decorative-only Aurebesh accent on the 404 page
  (src/app/[locale]/not-found.tsx + src/app/not-found.tsx).
- aria-hidden="true" with sr-only English fallback (A11Y-07).
- Loaded via next/font/local with preload: false (only fetched when the
  404 page renders; not preloaded on home or other routes).

Background:
The original CONTEXT D-15 specified FT Aurebesh from fontesk.com (SIL OFL).
Fontesk's distribution is gated behind an interactive form that fontesk's
download buttons cannot be programmatically resolved without a browser
session, so Plan 02-01 fell back to the Aurebesh_Rodian beta OTF released
on GitHub by AurekFonts under MIT. Both licenses (OFL and MIT) permit
unrestricted redistribution with attribution; this file documents both
the source and the redistribution chain.
